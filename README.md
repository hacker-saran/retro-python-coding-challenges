# Python Challenges

A curated, well-organized repository of competitive programming, algorithm, and data structure challenges solved in Python. These solutions were created during my college years to practice core algorithms, list manipulations, string handling, mathematical problem-solving, and matrix rotations.

## 📁 Repository Structure

The challenges have been categorized into logical directories under the `src/` folder:

```
Python-Challenges/
├── src/
│   ├── arrays/      # Array rotations, subsequence searches, and sliding windows
│   ├── strings/     # Diagonal print layouts, word casing, and backspace comparisons
│   ├── math/        # Mathematical puzzles and sequence generators
│   ├── matrix/      # Matrix patterns, traversals, and multi-directional rotations
│   └── misc/        # Miscellaneous data processors and score trackers
├── .gitignore       # Excludes python compiled caches and environment configs
└── README.md        # Portal and index directory
```

## 🛠️ How to Run

These programs are written in standalone Python (Python 3.x). You can run any challenge using standard python command execution:

```bash
python src/arrays/array_rotation.py
```
